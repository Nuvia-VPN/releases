# Nuvia 1.1.102 — изменения и проверки

**Исторический отчёт о версии 1.1.102. Ссылки установки ведут на актуальный выпуск 1.2.0.**

Android 7.0+ / ARM64, код версии **205**. Обновление устанавливается поверх предыдущего релизного APK с сохранением постоянной подписи.

## Изменения

- Исправлено восстановление доступа после снятия временной блокировки в панели: сохранённый вход остаётся на устройстве, подписка обновляется после нового разрешённого ответа сервера.
- При подтверждённом удалении аккаунта приложение отключает VPN, очищает связанные локальные данные и открывает экран входа.
- Временный сбой БД, сети или обычная ошибка авторизации не приводят к удалению сохранённого аккаунта.
- Поздний ответ для старого аккаунта не очищает данные нового аккаунта после переключения.

Встроенный компактный блок промокодов из 1.1.100 сохранён: реальные результаты сервера, плавное изменение высоты и автоматическое обновление подписки после активации.

## Условия автоматического выхода

Сервер должен подтвердить штатное удаление либо отсутствие исходного аккаунта в исправной текущей основной БД. Общие ошибки HTTP401/404, недоступность сервера или пропавшая связь с устройством не служат подтверждением удаления.

Для физического удаления записи из БД требуется подтверждение существования аккаунта, полученное приложением до удаления. Если старая установка его ещё не получила, приложение сохраняет данные вместо небезопасного автоматического выхода.

## Проверки

Эта версия ранее обновлена без удаления данных на Samsung SM-A165F и сохранённом QA-эмуляторе. Публичный APK повторно собран из того же неизменённого исходного кода; его контрольная сумма проверена отдельно, повторная установка на телефон для публикации не выполнялась. Сохранённый повторный вход на Samsung проверен после серверного обновления.

- Повторная сборка production release и vital lint со строгой проверкой зависимостей прошли.
- Общий JVM-набор: 4698 успешных проверок, 11 прежних пропусков, без падений и ошибок.
- Ранее выполнены пять изолированных native-проверок с настоящими AtomicFile и Android Keystore.
- Проверены постоянная подпись, версия и пакет APK, состав ARM64 и выравнивание 16 КиБ.

Подтверждённое удаление проверено серверными тестами на временных данных и изолированными Android-тестами. Полный живой сценарий удаления пользовательского аккаунта и полный цикл блокировка→разблокировка→VPN на физическом телефоне в этом выпуске не заявляются.
