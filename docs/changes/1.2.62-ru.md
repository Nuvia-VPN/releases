# Nuvia 1.2.62

- Исправлен сбой, из-за которого вход по почте мог останавливаться до отправки письма.
- Улучшено отображение отправляемых сообщений в поддержку.

[Скачать Nuvia для Android](https://github.com/Nuvia-VPN/releases/releases/download/v1.2.62/Nuvia.apk)

Установите APK поверх прежней версии, чтобы сохранить аккаунт и настройки. Если после обновления остался прежний экран ошибки входа, нажмите «Отменить» и начните вход по почте заново.

Требуется Android 7.0 или новее на 64-разрядном устройстве.
