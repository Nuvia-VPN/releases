# Nuvia 1.2.0

- Ответы поддержки могут приходить системными уведомлениями без текста переписки.
- Нажатие на уведомление открывает нужный чат, в том числе после закрытия приложения.
- Открытый чат восстанавливает связь после возвращения интернета.
- Счётчик непрочитанных обновляется вместе с подпиской.
- Улучшены вставка и редактирование кода приглашения.
- Повышена надёжность сохранённого входа и возврата в аккаунт.
