# Что изменилось в Nuvia 1.2.0

Ответы поддержки теперь могут приходить системным уведомлением «Поддержка ответила».
Текст переписки в уведомлении не отображается. Нажатие открывает нужный чат, в том
числе после обычного закрытия приложения.

Открытый чат восстанавливает соединение после возвращения сети. Счётчик непрочитанных
сверяется при каждом обновлении подписки — ручном, автоматическом и внеплановом.
Если push пропущен, такое обновление помогает обнаружить ответ. Исправлена фоновая
проверка ответов после обновления подписки, когда интерфейс неактивен.

Улучшены редактирование и вставка кода приглашения: курсор и выделение сохраняются
при форматировании. Повышена надёжность сохранения входа и возврата в аккаунт.

Приложение по-прежнему можно использовать без привязанной почты. Для обновления
установите новый APK поверх предыдущей релизной версии; постоянная подпись сохранена.

Для старых сессий без защищённого входа новые уведомления и сверка сообщений вместе с подпиской недоступны.

Системный Always-on VPN пока не поддерживается. Автовыбор использует Xray; реальные
подключения и смена сети с AmneziaWG/OLCRTC сохраняют ограничения, указанные в
описании приложения.
