# Nuvia 1.2.64

- Обязательные правила обхода VPN из подписки применяются автоматически. Такие приложения отмечены замком; общий переключатель обхода VPN не отменяет эти правила.
- Фон формы входа стал менее прозрачным, чтобы текст было легче читать.
- Убрано объявление с приглашением друзей на Главной.

[Скачать Nuvia для Android](https://github.com/Nuvia-VPN/releases/releases/download/v1.2.64/Nuvia.apk)

Установите APK поверх прежней версии, чтобы сохранить аккаунт и настройки.

Требуется Android 7.0 или новее на 64-разрядном устройстве.
