# Nuvia 1.2.29

Включены исправления 1.2.26–1.2.29:

- Исправлен вход после удаления аккаунта: повторная регистрация завершается по первой ссылке из свежего письма. Письма отображают отправителя Nuvia.
- Исправлен счётчик VPN-сеанса: трафик в обход VPN исключён, повторный подсчёт устранён.
- В разделе «Трафик и бонусы» убраны повторы лимита и пустой бонусный блок.
- После отвязки устройства можно продолжить вход или создать аккаунт, если сохранённого входа нет. Недействительный сохранённый вход больше не мешает продолжить работу.
- Экран приветствия показывает актуальное число стран либо текст без числа. Служебные записи больше не показываются среди локаций.
- Исправлено отображение общей квоты трафика устройств одного аккаунта и её исчерпания. Общий остаток может обновляться с задержкой и может отличаться от счётчика текущего соединения.
- В стандартной карточке Free рядом с остатком постоянно доступен переход к PRO с актуальными условиями.
