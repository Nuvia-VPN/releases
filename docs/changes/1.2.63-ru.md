# Nuvia 1.2.63

- В поддержку теперь можно отправить журнал приложения: нажмите «Логи», подтвердите прикрепление и отправьте сообщение.
- Поддержка может прочитать журнал прямо в обращении, чтобы разобраться в проблеме.

[Скачать Nuvia для Android](https://github.com/Nuvia-VPN/releases/releases/download/v1.2.63/Nuvia.apk)

Установите APK поверх прежней версии, чтобы сохранить аккаунт и настройки.

Требуется Android 7.0 или новее на 64-разрядном устройстве.
