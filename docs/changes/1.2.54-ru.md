# Nuvia 1.2.54

Версия для тестирования.

- Исправлено переподключение после смены локации.
- Добавлен переход «Зарегистрироваться» с экрана входа по почте.
- После удаления аккаунта повторная регистрация продолжается автоматически с понятным статусом подготовки, в том числе после перезапуска приложения.

Установите APK поверх текущей версии — аккаунт и настройки сохранятся.

[Скачать Nuvia для Android](https://github.com/Nuvia-VPN/releases/releases/download/v1.2.54/Nuvia.apk)

Android 7.0 и новее, 64-разрядные устройства.
