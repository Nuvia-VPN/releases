# Nuvia 1.2.25

- На экране подписки тарифы прокручиваются под закреплённой кнопкой оформления с мягким затемнением.
- На главной добавлено мягкое затемнение списка локаций под нижним меню.
- Последний период подписки удобнее прокручивать выше кнопки и меню, в том числе при крупном шрифте.
- Подсказка об устаревших данных показана над кнопкой оформления; при обновлении кнопка сохраняет положение.
