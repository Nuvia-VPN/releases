# Nuvia 1.2.77

При привязке почты таймер обновляется каждую секунду. Когда ожидание заканчивается, можно нажать «Повторить» прямо на том же экране.

[Скачать Nuvia для Android](https://github.com/Nuvia-VPN/releases/releases/download/v1.2.77/Nuvia.apk)

Установите APK поверх текущей версии, чтобы сохранить аккаунт и настройки.

Требуется Android 7.0 или новее на 64-разрядном устройстве.
