# Nuvia 1.2.61

- Обновлено VPN-подключение для Android.
- Когда общий трафик аккаунта заканчивается, уведомление приходит на устройства с включённым VPN, один раз за период.

Через локацию «Китай» некоторые сайты могут не открываться. В этом случае выберите другую локацию.

[Скачать Nuvia для Android](https://github.com/Nuvia-VPN/releases/releases/download/v1.2.61/Nuvia.apk)

Установите APK поверх прежней версии, чтобы сохранить аккаунт и настройки. Требуется Android 7.0 или новее на 64-разрядном устройстве.
