## Скачать

**Текущая версия — 1.2.59.** Для Android 7.0 и новее, 64-разрядных устройств.

[Скачать APK](https://github.com/Nuvia-VPN/releases/releases/latest/download/Nuvia.apk) · [Описание обновления](https://github.com/Nuvia-VPN/releases/releases/tag/v1.2.59)

Для обновления установите APK поверх прежней версии приложения — аккаунт и настройки сохранятся.

Когда остаётся меньше 500 МБ, Nuvia обновляет подписку при каждом открытии приложения, даже с выключенным VPN.

Если проверка новой версии в приложении не сработала, скачайте [APK 1.2.59](https://github.com/Nuvia-VPN/releases/releases/download/v1.2.59/Nuvia.apk) и установите поверх текущей версии.

## Возможности

- Бесплатный тариф: **1 ГБ в сутки** без ограничения срока.
- PRO: **500 ГБ в месяц**.
- Начало работы без почты; вход по почте и восстановление доступа.
- Выбор локации вручную или автоматически.
- Общий остаток трафика для устройств одного аккаунта.
- Активация промокодов и приглашение друзей.
- Поддержка внутри приложения с уведомлениями о новых ответах.
