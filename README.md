## Установить за три шага

1. Откройте нужный выпуск в **Releases** и проверьте требования к устройству.
2. В блоке **Assets** скачайте файл **`.apk`**.
3. Откройте файл на Android и следуйте подсказкам системы. Если потребуется, разрешите установку для приложения, из которого открываете APK.

> Архивы **Source code (zip / tar.gz)** создаёт GitHub. Это не установочные файлы Nuvia — для Android нужен **APK**.

## Версии и подлинность

В описании выпуска указаны изменения, версия, требования к Android и контрольная сумма **SHA-256** файла. Сравните её, если хотите проверить целостность загрузки.

В этом репозитории размещаются готовые приложения и сопроводительные материалы, а не исходный код приложения или серверной инфраструктуры.

## Поддержка

В приложении откройте **чат поддержки**. Не публикуйте в открытых обсуждениях ключи подписки, коды входа и личные данные.
